# 🎬 Lakhan Kashyap — Cinematic Interactive Portfolio

A modern, high-performance portfolio featuring a **Standard Developer View** and an immersive **4K Cinematic Interactive Anime Mode** inspired by Makoto Shinkai aesthetics.

---

## 🌟 Key Highlights

- **Dual Mode Experience**: Seamless toggle between a high-converting developer portfolio and a full-screen anime-style journey.
- **6 Cinematic Anime Chapters**:
  - **Chapter 01 (The Beginning)**: Rooftop sunset with living parallax, volumetric god rays, drifting feathered clouds, and city skyline.
  - **Chapter 02 (The Craft)**: Interactive cyber workspace featuring categorized skills and animated proficiency meters.
  - **Chapter 03 (The Odyssey)**: Sunrise mountain journey with production milestones at Shankrai Pvt Ltd and gentle sakura petals.
  - **Chapter 04 (The Creations)**: Futuristic lab with rotating 3D hologram hub and project showcase (MyToolboxs.online, Employee ERP, Pluggy).
  - **Chapter 05 (The Academy)**: Grand magical library with floating books, academic credentials (MCA, BCA), and verified certificates.
  - **Chapter 06 (The Future)**: Golden dawn skyline with one-click email copy, LinkedIn, GitHub, and phone direct links.
- **Zero-Lag Architecture**: GPU compositor-driven animations, CSS variables, and zero React re-render loops on scroll (guaranteed 60-120 FPS).
- **Interactive Developer CLI**: In-browser terminal emulator executing real commands (`help`, `skills`, `projects`, `exp`, `contact`, `clear`).

---

## 🛠️ Tech Stack

- **Frontend**: React 18/19, Vite, Modern ES Modules
- **Styling**: Pure CSS with hardware-accelerated transforms (`translate3d`), CSS custom properties, and responsive clamp typography
- **Motion & Scrolling**: Lenis ultra-smooth scroll engine, IntersectionObserver
- **Icons**: FontAwesome 6 Free

---

## 🚀 Getting Started

### 1. Clone & Install
```bash
git clone https://github.com/Lakhankashyap999/lakhan.git
cd lakhan
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```
